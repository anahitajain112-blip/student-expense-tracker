# Student Expense Tracker

A simple Streamlit web application that helps students track daily expenses and manage their monthly budget.

## Features
- Set a monthly budget
- Add daily expenses
- View total spending and remaining balance
- Calculate a daily safe-spending limit
- View category-wise expenses
- Receive budget warnings
- Delete expenses

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- GitHub
- Streamlit Community Cloud

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
